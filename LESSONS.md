# LESSONS.md — process rules (rule + evidence). Pruned at M3 (docs/retros/retro_M2.md, retro_M3.md).
1. Non-evaluating agents and reviewers get no test-label access; every brief says "compute no metric, score or count on test pairs", including top-k/score-threshold tables (they are metrics in disguise). (Part 1 D1; project D1; BRIEF_round1/2.md)
2. Fix PYTHONHASHSEED and all seeds for graph/community code; verify determinism by regenerating in a subprocess. (Part 1 Louvain tie-break bug)
3. Run a power simulation before freezing any statistical gate or CI scheme (and check the CI is well-defined: B, resampling unit, size matching). (Part 1 D2; round3_final B1)
4. Verifiers get only protocol + raw inputs, re-implement from raw data, sweep neighbouring configs, and report before seeing the harness numbers. (Part 1 a2f8622/460fd36; round1_ai_failure SHOULD-4)
5. Pre-register the exact look command; commit the "started" record before reading labels; one look; a relook is non-confirmatory. (Part 1 IFT look 1; round2_ai_failure M-B3)
6. Update the tree in the same commit as each result, and grep any "disclosed/see file X/done" claim against the file before writing it. (Part 1 stale tree; round1_pi M1; round2_pi gap)
7. Environment gotchas: run torch and LightGBM in separate pytest processes (OpenMP deadlock); wait on background jobs by PID (kill -0), never pgrep -f on a pattern in the waiter's own command line; set PART1_DIR explicitly in worktrees. (Part 1 final suite; M3 watcher loops; fzc_review)
8. Before any gate that needs a clean tree or pinned env, commit or isolate (worktree/own venv) concurrent agents' work; never let two writers share a gated tree. (round3_final untracked files; round2_ai_failure S-B5)
9. Draw the data-flow order (who is built on which split, who reads the lockbox when) before hardening code; review structure before harness. (round3_final B2/B3; round1_ai_failure MUST-7)
10. Reviews: independent roles, MUST/SHOULD/COULD, require label-free runs (tests, gate calls, scratch-repo simulations) and apply the real freeze edit as a test on the final artifact. (round2_ai_failure M-B1; round1_ai_failure)
11. Commit compact summaries + hashes, not repeated multi-thousand-line generated JSON; one source for version labels. (958cfda 12k-line diff; round3_final version label drift)
12. Stochastic tests: assert error rates over ≥50 sims against the guarantee the registered procedure actually gives; never a single-seed count threshold, and match code defaults (B, tail rules) to the registry text. (M3: GPD tail rule + B=1000 inflated null size 1.3–1.8×, hidden by a lucky single seed; 02f62ee)
13. Run the whole test suite (incl. cross-part guards) before each merge, not only the module's tests. (M3: lockbox firewall pattern list tripped the Part 1 guard, unnoticed since 10b5f90)
14. Firewalls are guards or tests, not prose; register the metric, its guarantee and a chance baseline before the test or freeze that uses them. (M3: proteomics read before FZ-C allowed only in prose, D5; pooled FDP vs BB chosen after code, D6; stability claim with no rewired baseline; retro_M3)
